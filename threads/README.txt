# Threads + Ring Buffer

Estrutura inspirada na organização mostrada pelo professor:

    threads/
    ├── inc/
    ├── lib/
    ├── obj/
    ├── src/
    │   └── main.c
    ├── Makefile
    └── threads

Comandos:

    make
    ./threads

Para limpar:

    make clean

Observação: o programa possui três threads em loops infinitos, então `./threads`
continua executando até ser interrompido com Ctrl+C.
